# Pokostats — téléchargements

Ce dépôt ne contient **que les installeurs** de l'application de bureau Pokostats
(tracker et entraînement poker). Le code source n'est pas publié ici.

- Page de téléchargement : https://pokostats.vercel.app/telecharger
- Chaque version est publiée dans l'onglet **Releases** (macOS Apple Silicon,
  macOS Intel, Windows x64), avec l'empreinte SHA-256 de chaque fichier.

L'application n'est pas encore signée par Apple / Microsoft : au premier
lancement, macOS demande de l'autoriser dans *Réglages Système → Confidentialité
et sécurité → Ouvrir quand même*, et Windows SmartScreen dans *Informations
complémentaires → Exécuter quand même*.

Pokostats n'est affilié à aucune room de poker. Réservé aux personnes majeures.

(appel non surtaxé).
